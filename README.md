# mywebsite - Code With Zain

Personal portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html`, `about-us.html`, `contact-us.html` - the 3 pages
- `style.css` - ONE shared stylesheet (colours are variables at the top)
- `script.js` - ALL the JavaScript (every feature is a small commented function)
- `*.jpg`, `*.svg` - images

## JavaScript features
1. Mobile hamburger menu
2. Current page highlighted in the nav
3. Header border appears on scroll
4. Footer year updates automatically
5. Project cards slide in on scroll
6. Lightbox: click a project to see the big image (arrows / Esc / click outside)
7. Stats on the About page count up
8. Contact form with validation (opens the visitor's email app)

## Before publishing
Open `script.js` and change `CONTACT_EMAIL` at the top to your real email.

## Adding a project
Copy one `<article class="project-card">` block in `index.html`, then change the image, title and text.
